Every control in the system

color-scheme is dark, so the select popup, the caret and the scrollbars follow the page rather than the OS. appearance is none on the field, the select and the button, so Safari adds no radius and no inner shadow. Autofill is overridden with an inset shadow, the only mechanism Chrome honours. Focus takes the ring inwards, because an outline at 3px offset collides with the panel edge. Constraints for generators

  • Accents are assigned per section via one data-accent attribute. A component never names a colour.
  • Blue is site-wide interaction: top bar action, primary button, cover, contact.
  • Use the eleven type steps as given. No intermediate sizes.
  • No border radius, shadows, gradients, glows or glass.
  • dark5 and comment are decorative. They never carry text.
  • blue0 and red1 are borders and markers. They are never type.
  • Uppercase is set in the mono face only, with tracking opened.
  • Dashed borders appear only on the empty state.
  • Reading columns never exceed the measure token.
  • Spacing comes from the 8px scale. No arbitrary pixel values.
  • Motion responds to input. Nothing animates on entry. No marquees, no scroll reveals.
  • No scroll progress bar and no gauge. The top bar is routes only.
  • One primary button per view.
  • The wordmark is live text. Its ampersand reads the section accent.
  • One h1 per page. Section heads are h2.
  • Native form chrome is suppressed. color-scheme is dark.
  • /kevin speaks as a person. Every other page speaks as the firm.
  • A capability group is a list, not a card. No hover, nothing to click.
  • The display step appears once per page.
  • A table never scrolls sideways on a phone. It stacks.
  • A proof figure claims only what the referenced engagement delivered.
